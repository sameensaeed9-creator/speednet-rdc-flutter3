SpeedNet Live Package Availability Flow
======================================

What was added:
1. backend/sync_packages.php
   - Fetches latest packages from SpeedNet/Airalo Partner API for Congo (CD) and Angola (AO).
   - Saves latest available package IDs in backend/speednet_live_packages.json.

2. backend/package_status.php
   - Checks if a website package/bundle is mapped and currently available.
   - Returns unavailable message automatically if Airalo discontinued/out-of-stock package is not in latest API response.

3. backend/speednet_package_map.php
   - Now has live sync + availability helper functions.
   - Mapping is still used, but approval/payment checks live availability first.

4. admin/approve_order.php
   - Before creating eSIM order, it checks whether selected package is still available.
   - If unavailable, admin order status becomes approved_speednet_package_unavailable.

5. backend/manual_payment_submit.php
   - Before accepting payment proof, it checks package availability.
   - User sees: This package is currently unavailable. Please select another package.

6. script.js
   - Buy buttons check package availability before opening payment flow.
   - Buttons can be disabled automatically when packages are unavailable.

EasyHost Cron Job:
Run this every 1 hour:
php /home/YOUR_CPANEL_USERNAME/public_html/backend/sync_packages.php

Or call URL every hour:
https://yourdomain.com/backend/sync_packages.php

Important:
- Keep AIRALO_CLIENT_ID and AIRALO_CLIENT_SECRET inside backend/api_keys.php.
- For production, Airalo live approval must be active.
- If live API has no Angola packages, Angola mapped packages will show unavailable automatically.
